# AI Lead Qualification & Intent Scorer

A client-side B2B revenue intelligence dashboard built with semantic HTML5, CSS3, and vanilla JavaScript. It evaluates inbound prospects, detects buying signals, prioritizes leads automatically, and exports pipeline data to CSV.

## Features
- **Automated Lead Scoring (0–100):** Weighs company segment size, executive seniority, and commercial intent signals.
- **Priority Queue Sorting:** Automatically ranks leads into **Hot (SQL)**, **Warm**, and **Cold** tiers.
- **Pipeline Value Estimation:** Calculates estimated Annual Contract Value (ACV) across qualified leads.
- **CSV Export:** One-click export formatted for direct CRM import.
